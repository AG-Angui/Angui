# 安归品牌素材

本目录提供 GitHub 组织头像、仓库图像和其他项目界面可以复用的初版品牌素材。

## 文件

| 文件 | 尺寸 | 用途 |
| --- | --- | --- |
| `angui-mark.svg` | 矢量正方形 | 品牌主标识、后续导出和界面使用 |
| `angui-mark-1024.png` | 1024 × 1024 | GitHub 组织头像原图 |
| `angui-mark-512.png` | 512 × 512 | 仓库、应用和普通头像场景 |
| `angui-mark-128.png` | 128 × 128 | 小尺寸预览和识别检查 |
| `angui-social-preview.svg` | 1280 × 640 矢量 | 仓库社交预览源文件 |
| `angui-social-preview.png` | 1280 × 640 | GitHub 仓库 Social Preview 上传图 |

## 设计含义

- **定位标记**：代表最后出现点、线索点、任务点和搜救地图。
- **房屋**：代表平安归家，也是“归”字最直接的视觉表达。
- **包围结构**：代表系统对老人、家属与志愿者的共同守护。
- **暖色门**：在安归绿中提供明确的归家信号，小尺寸下仍能形成识别点。

图标不包含文字，适合 GitHub 的圆形头像裁切。所有关键图形都位于中心安全区，缩小到 32 像素时仍保留“定位 + 房屋”的基本轮廓。

## GitHub 使用

### 组织头像

在 GitHub 组织设置中上传 `angui-mark-1024.png`。GitHub 会进行圆形裁切，不需要手动裁圆。

### 仓库 Social Preview

进入仓库 `Settings` → `General` → `Social preview`，上传 `angui-social-preview.png`。

## 生成方式

当前会话没有可用的内置图像生成工具，也没有配置图像生成 CLI 所需的 `OPENAI_API_KEY`。因此本版采用确定性的 SVG 矢量设计，并使用本地浏览器渲染为 PNG；没有调用外部生成模型。
