# 安归产品说明书

## 1. 产品概述

**安归**是一套面向失智老人走失搜救场景的 AI 与地图协同系统。产品服务于家属、搜救指挥人员和志愿者，通过统一的信息采集、线索审核、任务协同和案例复盘机制，减少搜救过程中的信息遗漏、重复沟通与安全风险。

产品核心价值：

> AI 帮助“问清楚、理清楚、讲清楚”，地图帮助“看得见、走得到、守得住”。

安归定位为搜救信息协同工具，不替代警方、消防、医疗机构、专业救援组织或现场指挥人员。所有影响案件判断、公开进展和任务执行的内容，均须经过人工确认。

## 2. 目标用户与痛点

| 用户 | 核心痛点 | 产品支持 |
| --- | --- | --- |
| 家属/知情人 | 情绪紧张、信息表达不完整、后续线索补充混乱 | 引导式问询、老人画像草稿、照片/地点/文字线索补充、公开进展查看 |
| 指挥人员 | 信息来源分散、线索难核实、任务与现场态势难统一 | 案件管理、线索审核、案情摘要、任务协同、地图态势与安全提醒 |
| 志愿者 | 不清楚本人任务与路线，现场反馈不及时，存在安全风险 | 个人任务、导航入口、位置上报、线索反馈与安全提示 |
| 新人志愿者 | 缺少搜救流程和安全规范训练 | 搜救手册、脱敏案例、防走失知识、题库与知识问答 |
| 后台管理人员 | 行动资料难以复盘、复用和治理 | 脱敏归档、案例审核、经验标签和知识素材管理 |

## 3. 核心业务闭环

1. **家属提交求助信息**
   家属通过引导式问询补充老人基础信息、身体与认知状况、行为习惯、最后出现地点、常去地点、随身物品及后续线索。

2. **生成并确认老人画像**
   系统将输入整理为标准化画像和线索草稿。AI 输出明确标记为“草稿”，须由家属或指挥人员确认后才能进入正式案件视图。

3. **指挥端审核线索与形成案情**
   新线索默认进入待审核状态。指挥人员将其标记为已确认、待核实、已排除、已失效或重复，并据此维护公共案情摘要。

4. **地图化任务协同**
   系统在地图上呈现最后出现点、线索点、任务点、常去地点、重点 POI 和授权范围内的模拟轨迹；指挥人员据此安排任务。

5. **志愿者执行与反馈**
   志愿者只查看本人任务及必要案情，可进行导航、位置上报和线索反馈。新反馈不会直接改变案件事实，而是进入待审核流程。

6. **案件复盘与经验沉淀**
   案件结束后，相关材料经授权、脱敏和人工审核后，形成时间线、复盘案例、经验标签及新人学习素材。

## 4. 产品功能结构

| 模块 | 主要功能 |
| --- | --- |
| 家属端 | 引导问询、老人画像确认、地点/图片/文字线索补充、公开进展、防走失知识 |
| 指挥端 | 案件创建与状态管理、成员授权、线索时间轴、人工审核、案情摘要、任务协同、地图态势 |
| 志愿者端 | 我的任务、导航入口、安全简报、位置与线索反馈 |
| 学习中心 | 队伍介绍、搜救手册、案例学习、防走失知识、理论题库 |
| 案例经验库 | 归档草稿、人工脱敏、审核发布、经验标签与学习资源沉淀 |
| 管理后台 | 账号状态、权限配置、审计事件、归档审核与安全管理 |

## 5. AI 与地图的角色

### AI 的作用

- 引导家属补齐关键信息；
- 将授权文本整理为老人画像、线索草稿和案情摘要；
- 辅助整理复盘材料、经验点和学习题目；
- 在知识库中基于已审核资料提供有来源的问答。

### 地图的作用

- 展示案件相关点位、任务点、常去地点和周边 POI；
- 为志愿者提供任务地点的导航入口；
- 呈现授权范围内的任务执行态势与轨迹；
- 支持天气、路况和区域风险等安全提示。

AI 和地图均为辅助能力：AI 不得把推测包装为事实，不得自动确认线索、发布案情或派发高风险任务；地图定位仅在任务需要、授权明确的范围内使用。

## 6. 安全与隐私原则

安归按“最小必要、最小权限、人工确认、全程留痕”设计。

- 家属仅能查看本人提交内容及已确认的公开进展；
- 志愿者仅能查看本人任务和必要案情，默认不可查看全量案件及他人完整轨迹；
- 指挥人员按案件授权查看线索、任务和必要态势；
- 管理员不因系统管理权限自动获得案件资料访问权；
- 身份信息、照片、病史、联系方式、精确位置、原始聊天记录等属于敏感信息，需严格授权和审计；
- 演示、测试和公开材料仅使用虚构或充分脱敏的数据。

明确不建设或不对外宣称的能力包括：未经授权接入监控或其他敏感系统、人脸识别、跨摄像头追踪、AI 自动判断老人位置、自动派遣人员进入高风险区域，以及向公众展示志愿者实时位置。

## 7. 当前 MVP 状态与规划边界

当前 MVP 已具备案件、成员授权、会话认证、线索提交、人工审核、案件状态流转、地点与图片补充、按角色裁剪的案情摘要、志愿者任务反馈、归档脱敏审核等基础闭环能力。

地图服务接入、外部模型调用、完整任务调度、实时位置与轨迹、知识问答/RAG、密码找回、多因素认证及生产级部署，仍需持续完善、验证和专项安全评审。产品当前用于脱敏模拟案件演示，不应视为已经在真实搜救场景中部署或验证。

## 8. 对外一句话介绍

**安归通过家属端、指挥端和志愿者端协同，把零散搜救信息整理为可审核的公共案情，把经确认的任务落实到地图与人员，并将每次行动沉淀为可复用的脱敏经验。**
