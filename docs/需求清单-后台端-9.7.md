# 后台端（指挥与管理）产品需求清单（9.7）

- **来源**：`安归四端产品内容9.7.xlsx` 中的“后台端”工作表。
- **适用对象**：指挥、后台审核人员和具备相应权限的管理人员，主要在桌面端进行高频、并发和风险敏感操作。
- **优先级说明**：`P0` 为案件事实、任务调度、审核、权限和关键安全操作的必备能力；`P1` 为首期协同与效率能力；`P2` 为复盘、预测和规模化增强。
- **估算边界**：各项为端内开发、测试与服务联调估算。AI、地图、语音对讲、账户安全和实时能力应复用共享基础设施，并与相关专项合并排期。

## 需求清单

### 【enhance】工作台与案件总览 - 案件列表、优先级和三栏指挥视图（P0）

- **预估工期**：5 人天
- **预估难度**：中高
- **预计修改范围**：后台首页、案件列表/筛选、案件详情工作台、全局搜索、侧滑详情和响应式布局；优先检查 `frontend/src/pages/CaseWorkspacePage.tsx`、Dashboard、案件 API 和共享布局组件。
- **修改要点**：首页按进行中/已结束、失踪时长、紧急程度排序；支持按案件号、姓名/代号、地区、队伍和状态检索；案件页采用“左侧案件/列表，中部地图或时间轴，右侧详情”的工作布局；案件顶部固定展示唯一 ID、状态、人员摘要、失踪时长、当前重点、成员和待处理数量。
- **最终验收标准**：指挥可在两步内找到目标案件并确认当前重点；紧急案件排序稳定可解释；桌面端信息不再依赖超长单列滚动；无数据、加载、错误、权限不足状态完整；现有案件角色和敏感字段权限不回归。

### 【feature】案件状态、画像与敏感信息区 - 受控事实工作面（P0）

- **预估工期**：4 人天
- **预估难度**：中高
- **预计修改范围**：案件状态机、老人画像详情、敏感信息折叠区、成员管理、当前重点维护、角色权限和审计接口。
- **修改要点**：统一草稿、受理、搜救、暂停、找到、关闭状态及允许动作；集中展示经确认的老人画像；病史、家属电话等进入敏感信息区，仅授权角色可展开；指挥可维护当前重点并区分 AI 建议与人工定稿；展示指挥/后台/志愿者成员和职责。
- **最终验收标准**：状态切换有权限、理由和审计；敏感字段不进入非授权响应/日志；当前重点可追溯人工编辑与 AI 建议来源；成员变动即时反映可见范围；案件 ID 在任务、线索、摘要和地图中可稳定关联。

### 【feature】案情摘要治理 - 自动生成、来源追溯、人工定稿与版本发布（P0）

- **预估工期**：6 人天
- **预估难度**：高
- **预计修改范围**：摘要生成服务、AI 输出 schema、摘要草稿版本状态机、人工编辑/审核/发布、来源引用、差异比对、前端摘要工作区和可见性 API。
- **修改要点**：摘要覆盖最后确认、有效线索、待核实信息、当前任务和安全提醒；新增重大确认线索后提示指挥是否刷新；每段可查看证据来源；明确区分 AI 原稿、手工草稿和人工最终稿；手工编辑、驳回、修订、发布、撤回必须具备可追溯版本链与允许动作。
- **最终验收标准**：摘要不把待核实信息写为事实；每个关键结论可定位到来源；AI 失败时有可读的模板降级；不同版本可查看正文、来源、差异和审核理由；仅经过人工发布且符合权限范围的版本可对志愿者可见；重复发布、过期版本和并发编辑有明确处理而非无上下文错误。

### 【feature】线索中心 - 搜索、结构化、审核、冲突/重复与可回滚决策（P0）

- **预估工期**：7 人天
- **预估难度**：高
- **预计修改范围**：线索列表/卡片、关键词和组合筛选、线索详情、原始媒体、AI 结构化候选、审核状态机、重复/冲突服务、关联线索、审核日志和地图联动。
- **修改要点**：线索按最新更新排序，支持关键词、地点、提交人、状态、时间、来源、可信度和批量待核实筛选；完整保留线索 ID、发生/提交时间、来源、一手/转述、原始文本/语音/图片；用统一标签表示已确认、待核实、低可信、无效、重复、冲突；AI 提取仅作为候选，人工确认后才入正式案情；支持标注原因、关联/合并、回滚和日志。
- **最终验收标准**：任意线索可找到原始内容和审核历史；筛选、地图和时间轴状态一致；重复/冲突建议不自动改变事实状态；驳回或排除有理由且可按权限恢复；AI 无法解析或返回英文/错误字段时不阻塞人工审核；审核操作性能、权限和审计达标。

### 【feature】时间轴与路线研判 - 确认事件驱动的空间时间分析（P0/P1）

- **预估工期**：5 人天
- **预估难度**：高
- **预计修改范围**：案件时间轴、事件聚合、地图定位、时间冲突检测、路线候选服务、交通关联和监控建议组件。
- **修改要点**：以确认线索、任务结果和监控信息形成时间轴；支持只看确认/只看任务等过滤；点击事件定位地图；对不可能同时成立的时间提供冲突提示；已确认节点可串为多条路线候选，不强行给唯一结论；公交/地铁、下一监控建议必须标注依据与不确定性。
- **最终验收标准**：时间轴只将已确认信息作为事实；待核实信息有明显状态；地图定位与事件时间匹配；路线候选可追溯到节点/交通依据；冲突提示不自动删除数据；无足够证据时不输出确定路线结论。

### 【feature】地图态势 - 分层、筛选、区域和资源协同（P0/P1）

- **预估工期**：6 人天
- **预估难度**：高
- **预计修改范围**：后台地图、图层控制、图例、点位聚合、区域绘制、时间过滤、轨迹回放、POI/资源查询、坐标权限和高德服务配置。
- **修改要点**：分层显示最后出现点、家庭/常去地点、已确认/待核实线索、志愿者位置和轨迹、已搜索/搜索中/待搜索/重点/风险区域；提供图层开关、图例和点位聚合；支持按时间查看地图状态和复盘回放；资源检索可选择任务中心、确认地点、当前位置或临时指定地点；监控、医院、社区等资源协同必须标记来源、联系人、联系状态和负责人。
- **最终验收标准**：地图图层、图例和状态颜色统一且角色可见范围正确；大量点位不影响基本交互；临时搜索中心不被持久化为案件坐标；资源协同防止多人重复联系；地图服务异常时提供可理解降级，不泄露密钥或内部位置。

### 【feature】任务调度与看板 - 从线索/地图创建到闭环反馈（P0）

- **预估工期**：6 人天
- **预估难度**：中高
- **预计修改范围**：任务创建/编辑、从线索或地图带入、负责人/小组分配、任务状态机、风险要求、回传、Kanban/地图/列表视图、AI 建议和通知服务。
- **修改要点**：任务可从线索和地图创建并携带必要上下文；AI 可给出任务建议但必须人工确认后才能发送；支持单人或小组、回传时限、风险要求；状态覆盖待接受、已接受、已出发、执行中、完成、异常；同时提供看板、地图和列表视图。
- **最终验收标准**：任务只向有权限且符合能力/范围的成员发放；志愿者状态与后台一致；异常和无法完成自动通知指挥；从线索/地图创建不会把未确认事实写入任务目标；批量任务场景下可按状态、负责人、时限定位并回溯创建依据。

### 【feature】通信、重要通知与安全调度 - 指挥可控的现场协作（P1）

- **预估工期**：5 人天
- **预估难度**：高
- **预计修改范围**：案件协作空间、指挥广播、指定成员消息、语音/转写、已读确认、关键消息置顶、志愿者安全状态、回撤/安全确认指令和实时连接状态。
- **修改要点**：案件内部通信支持文字、语音和必要媒体；指挥广播与普通消息区分；重要变更、回撤、安全确认要求已读/确认；消息可转线索候选但需审核；后台展示志愿者位置、最后回传、长时间静止、偏离、超时和极端天气风险；支持一键安全确认和一键回撤。
- **最终验收标准**：仅授权案件成员可通信；关键通知可追踪发送、送达、确认；语音对讲使用低延迟实时媒体方案而非轮询；安全指令有二次确认、审计和志愿者端明确反馈；家属和无权限成员不可读取内部通信/位置。

### 【feature】资源协同与复盘 - 联系去重、脱敏与经验沉淀（P1）

- **预估工期**：5 人天
- **预估难度**：中高
- **预计修改范围**：资源清单、联系人分配、联系状态、自动时间线、有效/无效线索复盘、关键决策、AI 复盘草稿、脱敏审核和知识候选生成。
- **修改要点**：维护医院、交通、物业/社区、监控排查等受控资源，避免将未经授权的机构信息公开展示；资源联系有负责人和未联系/等待/完成状态；复盘汇集时间线、有效/无效线索、关键决策和轨迹；AI 仅生成复盘草稿，人工审核和脱敏后才可沉淀为经验候选。
- **最终验收标准**：资源联系不重复、可追踪责任人；复盘可追溯案件事件但不默认暴露敏感信息；发布到学习端的内容经人工审核和脱敏；AI 草稿不能绕过审核或直接公开。

### 【feature】后台用户、角色、权限与审计管理（P0）

- **预估工期**：5 人天
- **预估难度**：高
- **预计修改范围**：账户管理、角色/全局能力、案件角色、组织/多城市隔离、数据审计、操作日志、分类标签和系统错误码治理；与账户安全中心、MFA 策略整合。
- **修改要点**：管理用户、角色和最小权限；支持组织/多城市作为后续扩展；所有案件、线索、任务、摘要、位置和安全操作记录审计；管理 Tag/Category；错误码映射为用户可理解中文提示，保留技术详情给受控运维。
- **最终验收标准**：角色变更立即影响 API 与页面可见性；管理员操作有理由、操作者和时间；数据导出/查看遵循权限；审计不可被普通用户篡改；系统错误不泄露密钥、坐标或原始敏感内容。

### 【enhance】桌面端效率、实时性与并发编辑保护（P1）

- **预估工期**：4 人天
- **预估难度**：中高
- **预计修改范围**：全局搜索、快捷键、侧滑详情、撤销、关键操作确认、实时更新提示、Loading/网络状态、版本冲突处理和前端可访问性。
- **修改要点**：高频操作支持快捷键和侧滑详情；状态误改提供时间窗内撤销；结案、无效线索、回撤等强制二次确认；实时更新不直接打断用户编辑，而是提示“有 N 条新数据”；两人编辑同一内容时用版本号提示冲突和合并/刷新选项。
- **最终验收标准**：实时更新不会使表单跳动或覆盖输入；网络断开有明确连接状态；关键操作均可审计且有确认；并发编辑不静默覆盖；复杂页面在常见桌面分辨率下信息清晰、无重叠。
