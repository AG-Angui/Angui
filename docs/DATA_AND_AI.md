# 数据与 AI 规范

## 1. 数据对象

### 1.1 老人信息

建议字段包括案件内代号、姓名（如确有必要）、年龄、性别、照片、体貌衣着、身体与认知状况、行动能力、随身物品、最后出现时间/地点、常去地点、曾居住地/工作地和家属联系方式。

其中身份、照片、病史、联系方式和精确活动地点均属于敏感信息。公开或演示视图应使用代号、局部信息或虚构数据。

### 1.2 线索

每条线索至少记录：

- 唯一编号和所属案件；
- 原始来源类型与受控引用；
- 报告时间、事件时间和地点；
- 内容摘要；
- 提交人和审核人；
- 状态及状态变化理由；
- 可信度的人工说明，而非仅有模型分数；
- 关联附件、任务和下一步动作；
- AI 是否参与提取及其版本信息。

### 1.3 任务

任务包括类型、目标、地点/范围、负责人、截止时间、风险等级、来源线索、状态、执行结果和反馈。高风险任务不得由 AI 自动创建并直接下发。

### 1.4 志愿者与轨迹

志愿者信息包括身份、角色、所属队伍、联系方式、能力/限制、案件权限和紧急联系人。轨迹数据包括任务、采集时间、坐标、精度和设备来源，并设置独立保留期。

### 1.5 案例与知识条目

案例包括脱敏摘要、时间线、关键线索、有效行动、问题复盘、经验标签、适用范围和审核记录。知识条目需要来源、版本、适用地区、有效期和责任人。

## 2. 信息生命周期

```text
采集 -> 分类分级 -> AI 辅助处理 -> 人工审核 -> 按角色使用
                                      │
                                      └-> 更正/驳回

案件结束 -> 冻结 -> 脱敏复盘 -> 经批准进入案例库 -> 到期删除/继续保留
```

接入真实数据前，项目负责人必须为每类数据明确采集依据、使用目的、可见角色、存储区域、保留期限、删除方式和应急联系人。

## 3. AI 任务边界

### 3.1 家属问询助手

允许：识别缺失信息、按固定主题追问、把用户输入整理为草稿。

禁止：替代报警/医疗判断、诱导家属提供无关隐私、根据有限信息断言老人位置或行为。

### 3.2 线索结构化助手

允许：从授权材料中提取候选人物、时间、地点、事件、来源和建议核实动作。

禁止：把推测变成已确认事实、自动提高线索等级、自动对外发布或自动派发高风险任务。

### 3.3 公共案情总结助手

允许：根据已授权、已分类的数据生成不同角色的摘要草稿，并明确未核实事项。

禁止：混入当前用户无权查看的字段、隐藏矛盾信息、删除重要不确定性或把旧摘要当作最新事实。

### 3.4 知识问答助手

允许：从审核后的手册和案例中检索答案，展示来源并提醒适用边界。

禁止：在无来源时编造流程、提供违法获取数据的方法、鼓励新人进入危险区域或越权行动。

### 3.5 案例整理助手

允许：在案件结束且材料获得授权后，生成脱敏草稿、经验点和题目候选。

禁止：未经人工复核直接进入知识库或训练集；保留可重新识别当事人的组合信息。

## 4. AI 输出最低要求

每项影响案件理解的 AI 输出应带有：

- “AI 辅助生成”标识；
- 生成时间；
- 使用的输入范围或来源引用；
- 草稿/已审核/已拒绝状态；
- 不确定和冲突信息；
- 审核人及审核时间（审核后）；
- 模型和提示模板版本（内部审计可见）。

模型给出的概率或置信分不能直接作为线索可信等级。线索可信度需要结合来源、时间、地点、佐证材料和人工判断。

## 5. RAG 与知识库治理

- 只索引已授权、已脱敏、来源可追溯并完成审核的资料。
- 原始聊天记录、完整病史、精确轨迹和个人联系方式默认不得进入通用知识库。
- 文档更新或撤回后，应能定位并删除对应切片和向量。
- 检索结果必须保留来源文档和版本；答案展示引用或至少展示依据名称。
- 对过期、地区不适用、互相矛盾的材料设置状态和优先级。
- 对知识库文档中的提示注入内容进行隔离，文档文本不得改变系统权限或工具调用规则。

## 6. 模拟数据规则

MVP 数据应满足：

- 姓名、电话、照片、住址、聊天账号和组织信息均为虚构；
- 地图可使用真实公共地点，但不得影射真实走失人员或未公开案件；
- 人像使用获得明确授权的素材、合规图库或生成素材，并记录来源；
- 聊天记录由项目组编写，不复制真实群聊；
- 演示账号使用固定低权限身份，不复用个人账号；
- 在界面和交付包中明显标注“模拟案件/虚构数据”。

## 7. AI 评估样例

在接入界面前，至少建立以下评估集：

- 缺失关键字段时能否继续追问，而非自行补齐；
- 时间、地点互相矛盾时能否保留冲突；
- 未核实线索能否始终保持未核实状态；
- 家属视图是否泄露内部任务或志愿者位置；
- 提示注入文本能否诱导模型输出敏感信息；
- 无知识库依据时能否拒绝编造；
- 输入包含真实风格电话、病史和坐标时，日志与输出是否正确脱敏；
- 模型或地图服务失败时，业务能否退回人工流程。
