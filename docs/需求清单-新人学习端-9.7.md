# 新人学习端产品需求清单（9.7）

- **来源**：`安归四端产品内容9.7.xlsx` 中的“新人学习”工作表。
- **适用对象**：尚未获得真实案件权限的新人、预备志愿者和需要复训的成员。
- **优先级说明**：`P0` 为合规、基础 SOP、可信知识与权限隔离能力；`P1` 为首期学习效率能力；`P2` 为模拟训练和成长体系增强。
- **估算边界**：以下为学习端与内容服务的开发和联调估算。课程、案例、题目与手册的真实内容生产、版权审查和脱敏由业务侧另行投入；AI 教练依赖受审核知识库和 RAG 基础设施。

## 需求清单

### 【feature】新人欢迎、学习路径与进度引导（P0/P2）

- **预估工期**：3 人天
- **预估难度**：中
- **预计修改范围**：学习首页、欢迎页、学习路径、课程目录、进度记录、推荐下一课和空状态；优先检查 `frontend/src/pages/LearningCenterPage.tsx`、学习 API、用户学习进度实体。
- **修改要点**：欢迎页解释加入后先学什么；按“入门 -> SOP -> 案例 -> 题库”展示路径和完成度；基于已学内容推荐下一课；不将未经组织的 PDF 直接堆给新人。
- **最终验收标准**：新人能在首屏看到当前学习阶段、完成度和下一步；课程完成/继续学习状态跨设备保存；没有可推荐内容时有可理解引导；学习端不提供真实案件入口。

### 【feature】入门课程 - 组织、职责、权限、隐私与安全底线（P0）

- **预估工期**：4 人天
- **预估难度**：中
- **预计修改范围**：入门课程内容模型、阅读页、完成确认、权限/隐私/安全知识卡、内容版本和审核发布流程。
- **修改要点**：覆盖队伍使命与组织结构、完整案件流程、指挥/后台/现场职责、权限边界、老人病史/照片/位置隐私，以及不擅自行动等安全规范；内容应使用可阅读模块、情景要点和确认，而不是单一长文档。
- **最终验收标准**：每项底线可被独立学习和确认；内容版本、发布者和更新时间可见；关键规则在后续测验/模拟中可引用；新人理解何时不能查看、传播或自行决策真实信息。

### 【feature】核心 SOP 学习库 - 首小时、问询、线索、地图、搜索与现场安全（P0）

- **预估工期**：6 人天
- **预估难度**：中高
- **预计修改范围**：SOP 分类、内容详情、章节锚点、Tag、阅读/完成状态、内容审核与检索索引。
- **修改要点**：建立老人走失第一小时、家属问询、线索可信度、城市路线追踪、监控排查、地图研判、搜索区域、荒野搜索、荒野/天气安全、社会资源、现场反馈和任务纪律等内容；不同 SOP 明确适用条件、禁止事项和升级联系条件。
- **最终验收标准**：用户能按主题和搜索快速定位 SOP；每篇 SOP 显示适用范围、风险提醒和来源版本；未经发布的草稿不进入学习端；内容在移动端和桌面端均适合阅读。

### 【feature】受审核知识库 - 分类、标签、经验与反常识内容（P0/P1）

- **预估工期**：5 人天
- **预估难度**：中高
- **预计修改范围**：知识条目、分类/二级分类、Tag、行为模式、走失场景、特殊场景、经验来源、审核发布、搜索索引和脱敏规则。
- **修改要点**：沉淀家属问询、线索判断、监控经验、地图研判、现场搜索、山地/水域/医院等特殊场景、指挥经验、社会资源、安全经验、失败经验和反常识；按老人特征、环境和场景标记；内容必须来自审核和脱敏后的材料。
- **最终验收标准**：知识可按分类、Tag 和关键词查找；用户能看到内容来源类型、发布时间和适用条件；失败经验不包含可识别案件个人信息；后台审核/撤回后学习端索引正确更新。

### 【feature】案例学习 - 分阶段信息、判断依据与误区复盘（P1）

- **预估工期**：5 人天
- **预估难度**：中高
- **预计修改范围**：案例列表、筛选、案例详情、分阶段内容、时间线、线索、判断依据、推荐动作、误区/风险和复盘总结。
- **修改要点**：案例按场景和难度筛选；背景只提供学习必要信息；按阶段展开线索，避免一次给出答案；展示时间线、关键线索、老队员判断、依据、推荐动作、不适用条件、常见误区、风险和最终复盘。
- **最终验收标准**：所有案例脱敏且经发布审核；阶段式内容不能通过 URL 或接口绕过提前读取答案；每个判断关联依据而非只给结论；案例支持在小屏阅读和继续学习。

### 【feature】题库与测验 - 选择、判断、情景、解析与错题沉淀（P1/P2）

- **预估工期**：5 人天
- **预估难度**：中
- **预计修改范围**：题库模型、题目分类/难度、答题页、结果解析、错题本、收藏、成绩和内容审核。
- **修改要点**：支持选择题、判断题、情景题、案例题和复盘题；答案后显示判断依据和相关 SOP，不只判断对错；自动收集错题，支持收藏；提供入门/进阶难度；成绩用于成长参考而不直接授予真实案件权限。
- **最终验收标准**：答题、解析、错题和收藏数据准确保存；正确答案和解析不在提交前泄露；题目变更后历史成绩可追溯版本；成绩不会绕过人工审批自动赋予志愿者/案件权限。

### 【feature】AI 教练 - 基于审核知识的 RAG 问答与不确定性控制（P0）

- **预估工期**：6 人天
- **预估难度**：高
- **预计修改范围**：知识检索、RAG 提示词和输出 schema、来源引用、会话 UI、推荐 SOP/案例、无法回答降级、审计和滥用防护。
- **修改要点**：支持自然语言搜救问题；回答只能依据已审核/已发布知识，展示对应手册或案例来源；证据不足时明确说明不知道；按问题推荐 SOP、案例和练习；后续可支持追问式教学“为什么这么判断”。
- **最终验收标准**：回答可点击查看至少一个相关来源；无知识依据时不臆造；不能使用 AI 获取真实案件、个人信息或内部调度；模型超时/失败有知识搜索降级；问答日志不存储不必要的敏感输入。

### 【feature】模拟训练 - 分阶段模拟案件、实时反馈与多维评分（P2）

- **预估工期**：8 人天
- **预估难度**：高
- **预计修改范围**：模拟案件数据、状态机、阶段线索释放、行动选择、反馈规则、错误继续、评分、老队员经验对比和结果报告。
- **修改要点**：提供完整模拟案件；按阶段释放信息；用户选择下一步行动后获得反馈；错误不立即结束训练；按判断、效率、安全等维度评分；将结果与已审核的老队员经验进行对照，不把模拟评分等同于真实资质。
- **最终验收标准**：模拟训练和真实案件数据完全隔离；阶段信息无法提前获取；选择、反馈、重试和结果可恢复；评分规则可解释；训练内容和引用经验均完成脱敏/审核。

### 【feature】成长档案与新人转志愿者申请（P2）

- **预估工期**：4 人天
- **预估难度**：中
- **预计修改范围**：课程进度、已学内容、测验成绩、能力标签、申请流程、人工审批、角色变更和审计。
- **修改要点**：展示课程进度、已学内容、成绩和基础线索/荒野安全等能力标签；满足配置条件时可提交成为志愿者申请；最终授权仍由人工审批，并与账户、MFA、隐私承诺和组织规则联动。
- **最终验收标准**：学习数据准确汇总且可解释；申请前置条件透明；申请不能自动获得真实案件访问；审批、拒绝、角色变更和撤销都有审计；权限生效后仍遵守案件级最小授权。

### 【enhance】知识搜索、收藏、最近查看与阅读体验（P1/P2）

- **预估工期**：4 人天
- **预估难度**：中
- **预计修改范围**：全局知识搜索、分类筛选、收藏、最近查看、阅读模式、卡片模式、案例时间线 UI、学习进度提示和无结果状态。
- **修改要点**：统一检索 SOP、案例和经验；支持按场景、老人特征、区域等过滤；收藏高频内容并记录最近查看；长文使用阅读模式，经验点使用短卡片，案例使用时间线；AI/搜索无结果时推荐相近分类。
- **最终验收标准**：搜索结果按权限和发布状态过滤；收藏与最近查看可跨端同步；阅读页不出现文本溢出、过窄行宽或难以返回的问题；无结果提供下一步建议而非空白页。

### 【feature】学习端权限与案例隐私隔离（P0）

- **预估工期**：3 人天
- **预估难度**：高
- **预计修改范围**：学习端路由/API 鉴权、内容发布状态、案例脱敏流水线、媒体访问、审计和测试。
- **修改要点**：新人不能访问真实案件、实时线索、人员照片、精确位置、内部调度和未发布复盘；案例内容在入库前完成脱敏；学习端只读取经审核发布的内容。
- **最终验收标准**：尝试修改 URL、接口参数、缓存或搜索索引均不能获取真实案件数据；撤回/下架内容立即不可见；媒体和附件使用受控访问；权限、脱敏和审计回归测试通过。
