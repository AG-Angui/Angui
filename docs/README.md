## 文档约定

- **已实现**：必须能指向仓库中的代码、配置、测试或可复现演示记录。
- **计划**：需求已确认，但尚未完成实现或验证。
- **候选**：存在多个技术选项，尚未作出架构决定。
- **禁止**：MVP 和后续迭代都不得在无新增授权、安全论证与负责人批准的情况下实现。

当原始说明与拆分文档不一致时，优先采用更严格的隐私与安全要求，并在提交中明确记录差异。产品范围发生变化后，应同时更新相关文档，避免演示材料、代码和权限说明互相矛盾。
