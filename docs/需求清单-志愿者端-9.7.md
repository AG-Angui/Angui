# 志愿者端产品需求清单（9.7）

- **来源**：`安归四端产品内容9.7.xlsx` 中的“志愿者端”工作表。
- **适用对象**：现场执行志愿者，主要在移动端、户外、强光/夜间、弱网和单手操作环境下使用。
- **优先级说明**：`P0` 为任务执行、位置、安全、线索上报和权限的基础能力；`P1` 为首期现场协同与风险控制；`P2` 为效率与体验增强。
- **估算边界**：下列估算包含本端和对应 API 联调。位置共享、实时语音、通知、天气和离线队列属于跨端基础设施，应按共享能力统一实施。

## 需求清单

### 【feature】首页与任务入口 - 当前执行、待接受与安全概览（P0）

- **预估工期**：3 人天
- **预估难度**：中
- **预计修改范围**：志愿者首页、任务列表、任务提醒、安全摘要、空状态；优先检查 `frontend/src/pages/VolunteerWorkspacePage.tsx`、任务 API、通知和安全状态接口。
- **修改要点**：首屏直接展示执行中任务；新任务明确展示接受/无法执行；简单展示今日完成数；展示天气、风险、回传要求等当前安全状态；不将新闻、知识库等低频内容放在首屏主工作流之前。
- **最终验收标准**：志愿者登录后可立即识别下一步任务；无任务时给出明确说明；任务变化和安全提醒可靠刷新；不可执行时可提交原因且指挥端可见；小屏幕下重点操作可单手完成。

### 【feature】任务详情与接单 - 目标、范围、依据和可执行状态机（P0）

- **预估工期**：5 人天
- **预估难度**：中高
- **预计修改范围**：任务详情页、接受/拒绝/暂停/完成/异常状态、任务依据、任务区域地图、老人照片预览、联系指挥入口和任务事件 API。
- **修改要点**：以一句话描述任务目标；展示地址、地图、搜索范围、体貌衣着、老人照片和必要的已确认依据；明确“看什么/查什么”，避免模糊任务；支持接受、无法执行、预计出发时间、已出发、已到达、搜索中、暂停、完成和无法完成；暂停/异常要求填写原因并通知指挥。
- **最终验收标准**：每个状态变更有时间、操作者和理由；志愿者只看到执行任务所需的最小信息；老人照片可放大；任务区域与地图一致；无法完成/异常不会被误判为失联；指挥端任务看板实时反映状态。

### 【feature】现场地图与导航 - 当前位置、任务区域、风险和必要线索（P0）

- **预估工期**：4 人天
- **预估难度**：中高
- **预计修改范围**：志愿者地图、当前位置、任务点/区域、导航唤起、已搜索区/风险区/确认线索图层、图例和地图降级。
- **修改要点**：默认聚焦任务点和任务范围；提供一键高德导航；按需要显示已搜索区域、风险区域、任务相关的已确认线索和地图图例；不展示无关案件内容或其他志愿者完整轨迹。
- **最终验收标准**：地图位置、任务范围、导航目的地和后台任务定义一致；地图服务不可用时保留文字地址、任务说明和导航替代；图例解释状态和颜色；没有权限的内部地点/线索不会下发到端侧。

### 【feature】任务期定位与轨迹 - 授权、周期上报、停止和异常处理（P0）

- **预估工期**：5 人天
- **预估难度**：高
- **预计修改范围**：定位授权页、浏览器定位、任务期位置上报、轨迹记录、最近位置缓存、任务结束停止、暂停共享说明和后台位置服务。
- **修改要点**：任务开始前清楚说明定位目的；任务期内按策略周期上传位置并形成轨迹；网络中断时保留最近位置和待上传记录；任务结束自动停止共享；特殊情况可临时暂停共享并要求说明；定位失败、精度异常和权限拒绝必须提示而非静默失败。
- **最终验收标准**：未授权不开始共享；任务开始/结束严格控制位置生命周期；断网恢复可补传且不重复；后台仅在权限和保留期内看到位置；暂停/恢复/结束均有审计；端侧不泄露其他成员完整轨迹。

### 【feature】快速线索上报 - 拍照、语音、文字、位置和人工确认预览（P0）

- **预估工期**：5 人天
- **预估难度**：中高
- **预计修改范围**：快速上报入口、相机/相册、长按语音、文本、当前位置和发生时间、AI 转写/提取 Preview、附件上传队列、待审核线索 API。
- **修改要点**：首屏或固定操作栏提供拍照、语音和文字上报；自动携带当前位置和当前时间，允许修正实际发生时间；语音可转写，AI 可提取人物/地点/方向但必须提供 Preview；所有上报进入待审核；“疑似发现目标”使用区别于普通线索的紧急流程。
- **最终验收标准**：照片、语音、文字和地点可在弱网下排队；用户可修正 AI 预览后提交；上报不直接写为案件事实；紧急发现流程能快速通知指挥且有防误触确认；失败重试不丢失媒体、时间或位置元数据。

### 【feature】任务反馈与现场异常 - 未发现、不可进入与支援请求（P0/P1）

- **预估工期**：3 人天
- **预估难度**：中
- **预计修改范围**：任务完成反馈、未发现结果、区域不可进入、风险/封闭/施工原因、请求支援、指挥端通知和地图状态同步。
- **修改要点**：将“完成搜索，无发现”作为有效结果；区域无法进入可记录风险、封闭、施工等原因并自动关联地图；支持请求支援；反馈后由任务状态机决定是否完成、异常或需重新分配。
- **最终验收标准**：未发现不会被当作无效操作；不可进入地点能在后台地图和任务日志中识别；支援请求及时可见；重复提交受幂等保护；敏感描述只对有权限人员开放。

### 【feature】案件通信、紧急通知与已读确认（P1）

- **预估工期**：5 人天
- **预估难度**：高
- **预计修改范围**：协作空间、与指挥文字/语音通信、图片/位置发送、任务组消息、广播通知、已读确认、实时连接和权限控制。
- **修改要点**：在案件内与指挥进行文字和语音沟通；指挥高优先消息置顶且有强反馈；关键通知要求确认收到；任务组消息仅限成员；图片和位置以必要权限发送；实时语音对讲通过 WebRTC + WebSocket 信令实现，不使用轮询传输媒体。
- **最终验收标准**：授权成员可收发消息，非成员不能加入；关键广播可看到送达/确认；断线和重连状态明确；语音实时性、权限和隐私满足协作空间规范；位置发送不改变任务期定位的同意和保留边界。

### 【feature】现场安全能力 - 天气、风险、回撤、SOS 与安全确认（P0/P1）

- **预估工期**：5 人天
- **预估难度**：高
- **预计修改范围**：天气/极端天气数据、夜搜模式、风险区域提示、偏离/超时/静止检测、回撤通知、SOS、安全确认和指挥端安全看板。
- **修改要点**：展示当前天气和极端天气强提醒；夜间启用高对比和更强安全提示；突出低洼、水域、荒地、枯井等风险地点；偏离区域、长时间静止和超时未回传先提醒本人，再按策略升级；回撤必须确认；SOS 位于易触达但防误触位置；支持一键安全确认。
- **最终验收标准**：所有安全提醒有可理解的原因、时间和操作；SOS 和回撤有二次确认、防误触和审计；安全事件不因网络短断而丢失；指挥可跟踪确认结果；风险提示不依赖未授权精确位置或未经验证的 AI 判断。

### 【feature】任务前微学习与现场规范提示（P1）

- **预估工期**：2 人天
- **预估难度**：低至中
- **预计修改范围**：任务详情的 SOP 卡片、荒野安全确认、现场注意事项、学习内容选择规则和完成记录。
- **修改要点**：按任务类型在接单/出发前展示 1 分钟 SOP；荒野/高风险任务要求确认关键安全卡；提示“不擅自进入水域”等现场注意事项；不强制跳转至完整知识库打断任务执行。
- **最终验收标准**：任务类型与展示 SOP 匹配；需要确认的高风险规则未确认前不能进入相应高风险执行状态；学习卡简短、离线可读；完成记录可供后台审计但不替代人工资格判断。

### 【enhance】户外移动体验 - 固定操作栏、弱网、离线队列与无障碍（P0/P1）

- **预估工期**：4 人天
- **预估难度**：中高
- **预计修改范围**：志愿者端全局布局、底部操作栏、本地离线存储、任务/线索上传队列、GPS 错误提示、夜间高对比、防误触和移动端测试。
- **修改要点**：固定“导航/上报/联系指挥”操作栏；大按钮和高对比适应夜间/强光；弱网缓存任务与待发送线索，恢复后提示上传；GPS 异常清楚提示；完成任务、SOS 等操作二次确认；优化单手和戴手套操作。
- **最终验收标准**：常见手机尺寸下关键操作始终可见；无网可查看缓存任务和保存待上传内容；网络恢复后可安全重传且不重复；高对比、焦点、触控面积和屏幕阅读器基础要求通过；不出现将失败隐匿为已成功的状态。

### 【feature】志愿者历史与最小权限可见性（P2/P0）

- **预估工期**：2 人天
- **预估难度**：中
- **预计修改范围**：我的任务记录、我的上报、历史筛选、数据脱敏和案件角色过滤。
- **修改要点**：支持查看个人历史任务和本人提交的线索；不提供全量案件、全量线索或其他志愿者完整轨迹；历史内容按案件保留和权限策略脱敏。
- **最终验收标准**：用户仅能检索与自己有关且仍有权访问的历史；离开案件或权限撤销后不可继续读取；任务和上报历史与服务端记录一致；敏感联系方式、内部调度和他人轨迹不泄露。
