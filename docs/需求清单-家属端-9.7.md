# 家属端产品需求清单（9.7）

- **来源**：`安归四端产品内容9.7.xlsx` 中的“家属端”工作表。
- **适用对象**：走失老人家属，主要使用移动端，可能处于焦急、弱网、单手操作或中老年用户协助操作的情境。
- **优先级说明**：`P0` 为建案、隐私和案件处置链路的上线前必备；`P1` 为首期应完成的效率和信息质量能力；`P2` 为后续增强。
- **估算边界**：下列工期为单项开发、测试和端内联调的人天估算；地图、AI、上传、通知、权限等共享基础设施若未具备，需要与对应端的工作合并评估。

## 需求清单

### 【feature】首页与案件入口 - 单一求助入口、已有案件恢复与待办（P0）

- **预估工期**：3 人天
- **预估难度**：中
- **预计修改范围**：家属首页、路由守卫、案件/建案草稿查询接口、案件状态标签、待办聚合接口；优先检查 `frontend/src/pages/` 的家属首页/进展页、`frontend/src/api/` 的案件与 intake 请求封装、后端案件和 intake 查询服务。
- **修改要点**：首屏仅保留“老人走失求助”主 CTA；已建案家属优先看到当前案件卡而不是再次创建；展示信息填写中、待受理、搜救中、已找到、已结束等统一状态；将待补信息组织成任务卡，明确下一步和截止/重要性。
- **最终验收标准**：无案件用户可一步进入建案；已有草稿或案件用户可在首屏恢复原流程；状态、待办、进展数据与服务端一致；首屏不出现多个相互竞争的主操作；移动端单手可操作且无空白状态。

### 【feature】建案流程 - 可恢复草稿、自动保存与六步信息采集（P0）

- **预估工期**：5 人天
- **预估难度**：中高
- **预计修改范围**：家属建案表单、步骤状态机、草稿保存/恢复 API、未保存离开保护、表单校验、进度组件；优先检查 `frontend/src/pages/FamilyIntakeForm.tsx`、intake API 和后端 `intake_session` 服务/实体。
- **修改要点**：提交求助后立即生成可恢复草稿；按“基础信息、身体状况、走失情况、行为习惯、地点、确认”分步填写；字段或步骤自动保存并展示保存状态；显示 `1/6` 进度并支持返回编辑；非关键项允许“暂不清楚/稍后补充”，关键项给出明确原因与补充路径。
- **最终验收标准**：中途退出、刷新、切换设备后可恢复最近已保存内容；网络失败时不丢失输入并可重试；用户可回退修改任一步；不确定项不会阻塞流程或被误记为已确认；完成确认后数据正确进入待审核/建案链路。

### 【feature】失踪人员标准信息档案 - 基础、体貌、健康、出行与随身物品（P0）

- **预估工期**：6 人天
- **预估难度**：中高
- **预计修改范围**：家属表单 schema、老人画像数据模型、敏感字段权限、照片上传组件、表单选项配置和管理端画像映射；涉及基础信息、衣着、明显特征、疾病/认知/行动能力、用药风险、公交/地铁/步行能力、手机/证件/定位器等字段。
- **修改要点**：姓名、年龄、性别、身高采用适合填写的结构化控件，身高和年龄允许约值；衣着使用颜色选项加自由描述；明显特征采用快速标签；疾病、联系方式、手机号码等敏感信息展示收集目的并限制可见角色；随身物品标记可核查状态；支持正面、侧面、近期生活照，并确定一张主图。
- **最终验收标准**：所有字段按必填、选填、敏感级别和“未知”状态校验；照片可预览、替换、删除和选择主图；管理端和志愿者端仅接收各自被授权的最小必要画像字段；画像内容不由 AI 补造；录入、保存、回显及权限测试通过。

### 【feature】最后出现与地点采集 - 时间、地点、来源和监控线索（P0）

- **预估工期**：4 人天
- **预估难度**：中高
- **预计修改范围**：最后出现步骤、日期时间控件、地图选点/地址解析、地点和线索模型、监控排查项生成、坐标隐私控制；优先检查家属表单、地点 API、地图组件和后端案件地点/线索服务。
- **修改要点**：最后确认时间支持日期时间和“大约”精度；地点以地图选点为主、文字地址为辅；信息来源固定为亲眼、监控、他人转述等结构化选项；当时行为支持预设和自定义；离开方向支持地图或文字并允许未知；“存在监控”可生成后台待排查项但不自动认定事实。
- **最终验收标准**：时间精度、来源和原始描述可追溯；地点选点/地址检索失败有手工输入降级；不持久化未确认的浏览器当前位置；监控信息进入待核实/待办而非已确认线索；全流程遵守地图与地点权限。

### 【feature】行为习惯与地点网络 - 常去地点、路线及远期记忆线索（P1）

- **预估工期**：5 人天
- **预估难度**：中高
- **预计修改范围**：常去地点卡片、路线编辑、地点分类和时间属性、公交/地铁线路字段、AI 问答补充入口、管理端地图同步；涉及家属表单、地点实体/接口、路线数据模型和地图展示。
- **修改要点**：支持公园、市场、医院、旧居、原工作单位、老家、亲友住所等多地点卡片；地点包含分类、重要性备注、时间属性和可选图片；固定散步/买菜路线以路线而非单点记录；常乘公交/地铁作为路径候选；“最近反复提及地点”由 AI 以问答形式补充，不能直接写为事实。
- **最终验收标准**：可添加、编辑、删除多个地点并标注分类/备注；路线可在地图上回显；未确认地点与确认地点状态区分清楚；敏感住址只对授权角色显示；AI 追问结果须经家属确认才可进入正式画像或地图。

### 【enhance】AI 问询与画像确认 - 缺项追问、矛盾提示和可编辑版本（P0）

- **预估工期**：5 人天
- **预估难度**：高
- **预计修改范围**：问询策略、字段完成度、AI 输出 schema、矛盾规则、画像卡片、版本记录和确认 API；优先检查 intake 初审/画像服务、AI gateway、家属表单和画像草稿组件。
- **修改要点**：识别关键缺项且每轮最多展示 1 至 3 个问题；按已有答案个性化追问；识别“不会坐公交/每天坐公交”等冲突并请家属确认；未知项明确标为尚未确认；允许跳过后再补；AI 画像以字段卡片显示，关键字段高亮，支持局部编辑和后续版本追溯。
- **最终验收标准**：用户不会被连续问题轰炸或卡死；AI 不会自动填补未知字段；矛盾项可定位到原答案并完成修正；画像每次更新有来源、时间和确认状态；提交指挥前家属可审阅、局部编辑并确认关键数据。

### 【feature】地图地点管理 - 家庭、最后出现、常去地点与备注（P0）

- **预估工期**：3 人天
- **预估难度**：中
- **预计修改范围**：家属地图页/嵌入式选点组件、地点卡片、图片附件、地点标签与时间属性、地图 API；涉及前端地图组件、地点接口和附件存储。
- **修改要点**：以家庭地址、最后出现点、常去地点为核心对象；支持旧居/工作地、自定义地点、重要性备注、地点图片和“每天上午/十年前工作”等时间属性；家属端以易懂文字和卡片辅助地图，不要求理解专业 GIS 操作。
- **最终验收标准**：核心三类地点可新增、编辑、删除和回显；地点备注和时间属性不丢失；地图加载失败可用文字地址继续填写；地点图片和地址按权限展示；不会将家属浏览器位置未经确认写入案件。

### 【feature】后续线索提交 - 文本、图片、语音、地点与预览审核（P0）

- **预估工期**：5 人天
- **预估难度**：中高
- **预计修改范围**：家属案件进展页、快速线索表单、图片/语音上传、地图点提交、AI 预整理、上传队列和失败重试；涉及 clue API、附件/语音服务、AI 结构化抽取和审核队列。
- **修改要点**：提供文字、截图/照片、语音、地图点/当前位置和微信转发内容的快速提交；可填写目击人联系方式但仅后台授权角色可见；AI 预整理时间/地点/人物并在提交前以 Preview 供用户修正；上传显示进度；弱网或失败后保留数据并可重试。
- **最终验收标准**：所有提交默认处于待审核，不能直接成为案件事实；图片/语音上传可显示进度与失败原因；失败重试不清空原输入或重复创建线索；预整理字段可修改且不产生无证据推断；联系方式、原始媒体和地点按权限隔离。

### 【feature】案件进展、通知与提交历史 - 面向家属的受控信息反馈（P0）

- **预估工期**：4 人天
- **预估难度**：中
- **预计修改范围**：家属案件进展页、通知中心、待补信息任务卡、个人提交记录、发布可见性策略；涉及公开进展 API、通知服务和家属授权过滤。
- **修改要点**：展示指挥确认并允许公开的案件进展；将后台补充请求做成待办任务卡；状态变化通过消息中心和页面状态同步；家属可查看本人提交历史，避免重复提交；系统通知与普通聊天严格区分。
- **最终验收标准**：家属只看到已审核且对家属公开的信息；新的待补事项可见、可完成、可追踪；状态变化有可读通知；历史记录准确列出本人提交但不泄露内部线索、调度和志愿者位置。

### 【enhance】移动端体验、隐私和可靠性 - 弱网、无障碍与草稿撤回（P0）

- **预估工期**：4 人天
- **预估难度**：中
- **预计修改范围**：全局移动端布局、空状态、加载态、错误提示、离开保护、隐私授权说明、草稿删除/撤回、前端无障碍样式和错误映射。
- **修改要点**：关键操作置于拇指可达区域并扩大触控面积；无案件、加载中、AI/地图/网络失败都有中文说明和后续动作；未保存输入离开时提醒；正式进入案件前支持删除/撤回草稿；对照片、病史、位置展示收集和使用说明；提升字号、对比度、焦点和屏幕阅读器支持。
- **最终验收标准**：常见手机宽度下无文本遮挡和横向溢出；弱网、断网和上传失败均可恢复；不展示仅含 error code 的错误；用户可理解并管理草稿和授权；家属无法看到未核实线索、志愿者位置和内部调度信息；无障碍基础检查通过。
